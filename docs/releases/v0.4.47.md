# Qnector v0.4.47 — Motion controls and resilient skills.sh installs

## Changes

- Added a persistent **Interface Animations** setting. Disabling it removes CSS animations and transitions, skips drawer navigation/close motion, and stops continuous Royal Gold Matrix canvas motion while keeping the interface fully usable.
- Existing configurations migrate with animations enabled, preserving the behavior of earlier releases unless the user explicitly turns motion off.
- Hardened skills.sh installation around the registry's canonical `skillId`. Remote skills whose upstream `SKILL.md` uses display-style names such as `Photoshop`, spaces, underscores, or other non-canonical casing are normalized to the canonical lowercase-hyphen skill ID during installation.
- Installed-state matching now uses remote provenance/canonical skill IDs so Discover results remain accurate when registry display names differ from installed folder names.
- Added regression coverage for the real-world `sfkislev/flue/photoshop` shape where upstream metadata declares `name: Photoshop` but skills.sh exposes canonical skill ID `photoshop`.
