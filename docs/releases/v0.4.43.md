# Qnector v0.4.43 — Memory Center

This patch includes the committed Memory Center changes after v0.4.42.

- Replace the dense Memory drawer with categorized, readable workspace and task memories, accessible detail views, local-only search labels and safer wipe confirmation.
- Display Memory v2 items that were not previously shown. Add bounded, read-only pagination for workspace/task memories and tasks, with workspace identity guards and accurate loaded/total labels.
- Synchronize the MCP-reported version with the packaged desktop and fail builds if version declarations disagree.
- Reduce the initial Memory snapshot to 30 facts and 12 tasks, preserve explicit load-more controls, coalesce memory events to one scheduled refresh per 500 ms, and prevent overlapping refresh requests.
- Preserve persisted memories, running tasks and the existing external MCP tool interface. Social Reader work in the separate uncommitted working tree is not included.

**Scope:** This is a Memory UI and inventory patch, not a verified cure for ChatGPT message delivery timeouts. SSE comments cannot override upstream response deadlines. Existing long-running process handling returns a process ID for polling rather than waiting for one long MCP response. The end-to-end ChatGPT-through-tunnel 8-case timeout matrix and manual visual QA of the installed Memory drawer remain separate acceptance work.
