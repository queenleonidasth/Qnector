# Qnector v0.4.37-rc.1 — durability and MCP timeout mitigation (PRE-RELEASE)

**Experimental release candidate, NOT a stable upgrade.** Do not enable durable preview on a production workspace without a backup. The currently installed v0.4.36 is not modified by publishing this release.

## Changes

- MCP Streamable HTTP: conditional SSE keep-alive comments every 15 seconds, only after SSE headers and between complete frames. JSON responses and stdio framing remain untouched. This cannot extend ChatGPT Web model-stream deadlines or fix every interrupted connection.
- MCP tool results: bound structured JSON at 256 KiB and base64 image attachments at 2 MiB. Oversized content is explicitly omitted with continuation metadata/task handles when available; operations are not silently replayed.
- Opt-in durable daemon, worker and Windows Job Host: disk-backed task handles, stable idempotency keys, independent work after HTTP/stdio frontend loss, get/wait/result/paginated output/cancel and a basic Jobs panel scoped to the active workspace. `tasks.start` acknowledges immediately by default; this does NOT transparently make the eight legacy tools durable.
- Stdio diagnostics are routed from console.log/info/debug/warn to stderr so stdout remains JSON-RPC only.
- Harden daemon journal/token ACL checks; tolerate a verified disappearance of a worker temporary file during a concurrent ACL audit, while rejecting unexpected permissions on existing files.

## Verification

- 291/291 unit/integration tests passed across 61 files; TypeScript typecheck and ESLint passed on the prior feature commit before the version bump.
- Windows packaging gate passed including daemon bundle smoke, packaged recovery and packaged stdio parity. The tagged release must be rebuilt from the clean release worktree and verified again before GitHub assets are published.

## Known limitations and rollout

- Durable Preview remains OFF by default (`QNECTOR_DURABLE_PREVIEW=1` is explicit opt-in). The original synchronous MCP tools can still time out.
- WorkflowManager/process tools are not fully converged into the durable daemon; no promise that all workflow steps survive Desktop shutdown.
- Full upgrade/drain/migration/rollback and reboot or power-loss tests, cross-account ACL security and 24-hour soak remain unverified. Do not advertise this build as stable or enable automatic rollout.
- Back up configuration and workspace before trying an opt-in preview; retain v0.4.36 as the rollback baseline. No application restart or install is performed by release publication.
