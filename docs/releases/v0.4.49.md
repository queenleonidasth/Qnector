# Qnector v0.4.49 — Sharper drawers and truthful Memory freshness

## Changes

- Fix blurred text after opening Skills and other drawer pages by releasing persistent Chromium compositor promotion after the opening animation settles.
- Keep GPU/compositor hints only while drawer/page transitions are actively animating, so text rasterizes sharply on the first open without requiring a tab switch.
- Fix Memory Center freshness semantics when no ChatGPT session binding exists: the first panel is now **Latest Activity** and selects the newest persisted Qnector task activity, including **General workspace activity**.
- Preserve **Last Session** only for explicitly session-linked Memory tasks; Qnector still does not fabricate or store ChatGPT transcript text.
- Keep live Memory v2 refresh behavior intact while making the displayed timestamp/task reflect the newest saved activity instead of a stale named task.
