# Qnector v0.4.52 — ChatGPT Plan/Act Task Controller

## Improvements

- Added `plan_panel(memoryTaskId)`, a dedicated read-only MCP tool that opens the interactive Task Controller inside supported ChatGPT conversations.
- Adopted the MCP Apps `_meta.ui.resourceUri` contract and ChatGPT-compatible `_meta["openai/outputTemplate"]` alias, using a new cache-versioned UI resource URI.
- Redesigned the controller with live Plan and Act tabs, task identification, revision/approval state, checklist controls, Refresh, and Continue in ChatGPT.
- Kept approval as an explicit `mode_approve(expectedRevision)` tool call. Mode changes and checklist updates go through Qnector MCP, not local mock state.
- Avoided rendering duplicate widgets on ordinary `mode` and `mode_approve` data operations.
- Expanded MCP integration and resource/UI syntax tests; updated tool-count regression tests and connection instructions.

## Activate in ChatGPT

1. Install this Qnector build and verify its active version is 0.4.52.
2. In ChatGPT Settings → Apps / Plugins, find Qnector and refresh its tool list. Workspace administrators may need to review/publish new tools.
3. Enable `mode`, `mode_approve`, `inspect` and `plan_panel`, then start a new chat with Qnector enabled.
4. Ask ChatGPT: "Use Qnector to start a task, enter Plan Mode and show the Task Controller panel."
5. Review the live plan before using the Act tab. ChatGPT may also ask for consent to the approval tool.

The Task Controller is an MCP Apps inline panel; Qnector cannot add a permanent native Plan/Act button to ChatGPT's composer.

## Limits

The UI requires an MCP Apps-capable ChatGPT host and a refreshed custom app tool snapshot. Local source tests and MCP HTTP integration tests cannot substitute for an actual interactive ChatGPT host rendering test.
