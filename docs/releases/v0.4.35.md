# Qnector v0.4.35

Qnector no longer exposes or executes the public `system.parallel` action.

- Removed `parallel`, `calls`, `maxConcurrency` and `policy` from the `system`
  MCP schema.
- Removed the registry fan-out path so hidden `action=parallel` requests are
  rejected as invalid actions instead of starting nested tool calls.
- Updated the MCP server contract test, grouped-tool tests and tool reference
  to require separate top-level calls.
- Retained External MCP client actions (`mcp_servers`, `mcp_tools` and
  `mcp_call`) from v0.4.34.

This change removes only the public ChatGPT/MCP batching action. Internal
PowerShell workers and workflow graph scheduling remain available for their
own bounded execution semantics.

Validation: TypeScript typecheck, ESLint, all 243 tests across 40 files, and
the Windows package gate passed.
