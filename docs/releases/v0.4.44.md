# Qnector v0.4.44 — Simple English Memory Center

This patch updates the Memory Center introduced in v0.4.43 to make the saved state easier to understand.

- Replace the crowded Memory screen with three English-language sections: **Last Session**, **Current Task**, and **Activity Log**.
- Show the most recently linked session's saved task topic and context, when Qnector recorded a session binding. If no binding exists, clearly label the newest saved task as a fallback; no ChatGPT transcript or conversation summary is fabricated.
- Display current, non-completed task progress and next steps without treating a successful tool call as proof that an entire task is complete.
- Show a bounded, timestamped list of saved tool events and file changes. Keep search, additional task/memory pagination, export, and destructive memory controls tucked into collapsible sections.
- Read the most recent session binding with one bounded, read-only, workspace-scoped database query; do not add background polling or modify memory persistence.
- Keep the existing Memory Center refresh throttling and initial load limits from v0.4.43.
- Preserve the existing MCP tool interface, stored memories, workspace separation, and durable task handling. Uncommitted Social Reader work in the separate development tree is not included.

**Verification:** TypeScript, ESLint and production build pass; full test run passes 337/337 with one worker. When run with two workers, two Windows daemon integration tests timed out, then passed individually and in the serial full run. Manual visual QA of the installed UI and the ChatGPT → Tunnel → Qnector timeout matrix are separate checks; this release does not claim to cure end-to-end message timeouts.
