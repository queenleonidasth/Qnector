# Qnector v0.4.52 — Windows pre-release

This **pre-release** is for evaluation. It is **not** designated stable.

## Changes
- Plan/Act v4 with explicit approval and revocation, stale revision/step protection and preserved checklist progress
- MCP Apps UI compatibility for older cached panel URIs
- Packaged TypeScript diagnostics fixes
- UX improvements: scroll/focus, responsive Plan panel, desktop error accessibility
- Durable task recovery and packaged MCP parity checks

## QC
- TypeScript, ESLint, 368/368 automated tests and production dependency audit passed on 2026-10-11.
- Electron acceptance checked Workspace, Memory, Skills, Settings and Runtime at four viewport sizes.
- Full eight-case ChatGPT-through-tunnel 30–300s timeout/progress/keepalive matrix **has not been completed**. Long tool calls should prefer durable task handles and explicit polling; no universal disconnection fix is claimed.

## Security / Installation
- Windows installer and portable executable are currently **unsigned (Authenticode NotSigned)** and can trigger Windows security warnings. Verify SHA-256 values before installing; do not disable system protections to install.
- Do not install over an active Qnector session without a verified backup and rollback plan.
- No signing certificate or signing assurance is implied by the packaging log.

See docs/native-ui-plan-act-release-qc-2026-10-11.md and docs/TIMEOUT_DIAGNOSIS.md for evidence and gaps.
