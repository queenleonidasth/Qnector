# Qnector v0.4.46 — Retire the Agent Reach pilot

This release removes the experimental Agent Reach / Social Reader integration from Qnector. It is a feature-removal release based on v0.4.45, not a new social-connector release.

- Remove the `social` MCP tool, Agent Reach / OpenCLI / YouTube / Facebook reader implementations, their setup IPC/preload methods and the Social Connections settings panel. The eight existing core MCP tools remain; the independent `tasks` tool remains available when its durable daemon is ready.
- Stop bundling the `social-reader` Agent Skill, remove its live/social-specific smoke scripts, and enforce its absence from new Windows packages. Verify that HTTP and stdio no longer advertise `social`.
- Preserve previously saved optional `social` settings only as inactive legacy config data so upgrades and unrelated settings changes do not discard existing user preferences. Newly created configurations do not include social settings. No browser login, account, personal profile, pre-existing integration executable, or user file is removed by the application.
- Preserve the existing Durable Runtime, Memory Center, existing eight tools, updater, and UI unrelated to the retired pilot.

**Important upgrade note:** Previously installed integration executables under the user's local Qnector integration directory and user-installed skills are not automatically uninstalled. The new installer does not ship the bundled `social-reader` Skill or make its retired MCP tool callable. Qnector v0.4.45 remains available for rollback.

**Release verification:** version sync, clean source tree and matching build provenance, typecheck, ESLint, Prettier, full unit/integration suite, MCP smoke, Windows Job Host and daemon recovery, HTTP/stdio parity, packaged Windows Setup/Portable and packaged runtime smoke, plus verification of Git tag, GitHub release and uploaded asset sizes.
