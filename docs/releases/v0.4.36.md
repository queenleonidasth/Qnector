# Qnector v0.4.36

Hotfix for packaged desktop configuration updates.

- Adds `@modelcontextprotocol/client` as a direct production dependency of the
  desktop app so Electron Builder includes it in `app.asar`.
- Fixes `Error invoking remote method 'config:update'` / `ERR_MODULE_NOT_FOUND`
  when the renderer updates configuration and the main process lazily starts
  the MCP runtime.
- Adds a release-pipeline regression test for the packaged runtime dependency.

Validation includes the full test suite, typecheck, lint, Windows packaging,
and a packaged runtime import probe for `@qnector/mcp-server`.
