# Qnector v0.4.54 — Plan Mode 2.0

## Changes
- **Chat-first Plan Mode:** every activation or return to planning triggers the locally installed `obra/superpowers` process skills (`using-superpowers`, `brainstorming`, `writing-plans`). The AI is instructed to interview the human one material decision at a time in ChatGPT before finalizing a build plan.
- **Structured decision log:** questions, human answers, and AI-delegated choices (including attribution, alternative options and rationale) persist across reconnects per task.
- **Approval safety:** unfinished planning, unanswered decisions, missing required skills and stale revisions are not eligible for approval or project mutation.
- **Final-only Plan Panel v5:** displays the full design, implementation plan and human/AI decisions in a safe HTML view. Legacy v2/v3/v4 resource URIs remain compatible.
- **Act continuation:** after the user explicitly approves a ready revision, the panel requests one ChatGPT follow-up where supported. Execution is not simulated when the host does not provide this capability.
- Legacy approved Plan/Act tasks remain loadable without losing their completed checklist.

## Windows installation
Windows Setup and Portable executables are intentionally **unsigned** (`Authenticode: NotSigned`) under the repository owner's explicit waiver. Windows SmartScreen may warn; do not disable security protections to install. Check the published hashes and download only from this repository's GitHub Release.

## Limits
The client and the model must cooperate with Plan Mode's question/answer protocol. The server enforces recorded state and approval gates, but cannot guarantee a model independently asks every conceivable question. The separate historical eight-case live ChatGPT-to-Tunnel 30–300-second diagnostic acceptance is not claimed here.
