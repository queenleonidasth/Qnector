# Qnector v0.4.53 — Stable Release

Qnector v0.4.53 includes the tested Plan/Act v4 controller, explicit approval and revocation confirmation, stale-plan guards, persistent checklist progress, packaged TypeScript diagnostics fixes, durable task recovery, and native UI accessibility improvements.

## Verification
- 368/368 automated tests passed; TypeScript, ESLint, security audit and Windows packaging smoke tests passed on the preceding code revision.
- Native renderer acceptance tested five screens in four viewport sizes, with keyboard focus, reduced motion, scrolling and error states.
- The full eight-case (30–300 second) real ChatGPT-through-Tunnel timeout/progress/keepalive matrix has **not** been completed. Therefore no universal long-running call reliability guarantee is made; use durable tasks and polling for long jobs.

## Windows downloads
- Setup and Portable are **unsigned** (Windows Authenticode `NotSigned`), as explicitly accepted by the repository owner. Windows SmartScreen warnings may appear. Do not disable system security protections to install.
- Use the SHA-256 hashes provided in the release assets/checksums for integrity verification.
