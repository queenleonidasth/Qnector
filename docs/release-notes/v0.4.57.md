# Qnector v0.4.57 — NoPlan Stability Release

Qnector 0.4.57 focuses on **correctness and reliability**. Additional feature development and unverified performance experiments are deferred.

## Fixes and compatibility

- Remove the Plan/Act controller, Plan Panel, interactive plan approvals and associated MCP tools, resources, prompts and UI state as requested. The normal **eight grouped MCP tools** remain available: `system`, `workspace`, `files`, `process`, `git`, `memory`, `browser` and `computer`. Existing background/durable tasks and Memory are retained.
- Fix workflow recipe execution to **preserve sequential failure dependencies by default**. Independent read-only Git checks can execute concurrently only through explicit opt-in, avoiding execution of a dependent step after an earlier failure.
- Preserve document parsing failures (including password-protected/corrupt PDF errors) instead of caching an unsuccessful result as valid data.
- Reduce repeated read/search costs with bounded, revision-aware caches and an on-demand LSP session pool while checking result hashes and invalidation. These optimizations do not claim a universal startup or ChatGPT latency improvement.
- Make acceptance tests resilient to shared test-fixture races by running integrity-sensitive release tests without parallel test-file execution.
- Keep existing Workspace Scope, permissions, user settings, tray, animations, activity feed and native integrations; no new features are introduced in this release.

## Updating from 0.4.56

The ChatGPT integration may cache the previous MCP tool schema. **After updating the desktop bridge, reconnect or rescan the existing Qnector app/tool connection** so the retired Plan Mode tools disappear. External ChatGPT permissions remain controlled by the host.

If an existing task is active, allow it to finish or use the normal durable task recovery flow before replacing the running desktop bridge. This release does **not** automatically modify a user's installed Qnector.

## Validation and known limits

- Typecheck, ESLint, serialized acceptance tests, local HTTP/stdio MCP smoke, native Job Host/UIA, durable recovery and exact-package SHA-256 evidence are release checks.
- User-requested companion-application checks (live ChatGPT Host and candidate Tunnel) were explicitly **SKIPPED**, not treated as PASS. The complete all-workload cold-process/CPU/RAM performance suite remains **UNKNOWN**.
- Windows Setup and Portable are currently built without an Authenticode signature. Windows SmartScreen may show an unknown-publisher warning. Verify both asset SHA-256 digests from the release before running.
- No full host/model round-trip latency, gaming frame-time or production installation/rollback claim is made by this release.
- Tracked QA exceptions: `docs/performance/noplan-qa-exceptions-2026-10-16.md`. Validated package attestation and regression output are retained in the candidate build folder.

This is a **stability-focused release under the user's reduced external-app test scope**, not a claim that every optional performance target or third-party-host workflow was certified.
