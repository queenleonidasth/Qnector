# Qnector v0.4.60 - Memory Reliability and Orb Disconnect

Stable release. Changes since v0.4.59:

- Fixed Memory V1/V2 parity: note updates preserve category and tags; deletion by either legacy or V2 ID removes corresponding copies; scoped clears no longer leave stale V2 notes.
- Memory health now reports legacy/V2 consistency and missing or stale entries; working-set diagnostics distinguish saved checkpoint freshness from newer tool activity.
- Preserved Workspace scope restrictions and user-controlled chat excerpt recording; no passive ChatGPT transcript capture.
- Improved Live Activity layout: fixed right-side status column so SUCCESS badges align regardless of task name or duration.
- Streamlined Dashboard by removing duplicate LINK STABLE and loopback URL; OPEN CHATGPT opens the normal ChatGPT home.
- Improved Queen Orb effects with restrained orbital accents, bounded motion, smaller orb and smoother hold-to-disconnect.
- Changed disconnect-only charging indicator and hold pulses to ember orange/red, keeping normal orbital effects gold.

Local REA reverse-engineer-anything Skill from morluto/rea can be installed separately through Qnector's Skill registry; this release does not bundle or auto-register the REA MCP server.

## Notes
- Windows binaries are distributed as Setup and Portable; preserve existing Qnector user data when upgrading.
- Electron/Windows tests and packaged runtime acceptance are part of release verification. Actual ChatGPT tunnel and end-user hardware behavior depend on the target machine.
