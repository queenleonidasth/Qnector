# Qnector v0.4.58 — Royal Liquid Glass Preview

**Preview release:** This build lets users inspect and evaluate the redesigned desktop UI before all animation-rework acceptance criteria are complete. It is not a claim that every hardware, game or live-host condition has passed.

## Visual changes

- **Royal Liquid Glass:** Reworked layered materials, translucency, reflections, focus and hover feedback throughout Dashboard, Dock, Drawer, Workspace, Memory, Skills, Runtime, Settings, Setup and Updater.
- **Queen Orb:** Cleaner, sharper portrait compositing without a visible square image edge, refined molten/glass effects and a corrected three-second hold indicator.
- **Royal Silk ambient background:** Replaces the Matrix-style falling glyphs with warm flowing ribbons, caustics and soft motes.
- **Shared VSYNC animation clock:** Orb and ambient Canvas use a single window-aware native requestAnimationFrame loop. Stops continuous animation when hidden, disabled or OS Reduced Motion applies.
- **Graphics modes:** Full / Balanced / Eco / Off provide a performance choice; complexity and maximum device-pixel-ratio adjust without intentionally capping animation to a low frame rate. Local FPS and p95 sampling is opt-in.
- **Interaction:** Faster Drawer retargeting without an artificial click lock; per-tab scroll restoration, bounded Activity virtualization, vector navigation icons and responsive keyboard focus.

## Reliability improvements

- Fix Setup Wizard Escape and keyboard focus handling when it is layered above an open Drawer. Uses actual overlay stacking instead of DOM order.
- Correctly retain Setup form input values between Back/Continue, show required-field validation, disable submission while pending and recover visibly from errors.
- Preserve honest updater states: only display determinate progress when provided by the update backend; avoid competing spinners and false success.
- Preserve the existing **NoPlan** architecture from v0.4.57, the Qnector bridge, MCP tooling and local Memory.

## Validation performed

- TypeScript, ESLint and production build: passed.
- **466/466 automated tests across 101 test files passed** on the clean v0.4.58 release source.
- Native Electron: 20 view/motion-state combinations (Balanced, Off, global animation Off, OS Reduced Motion), Setup and Updater synthetic state tests; zero reported renderer console errors.
- 120-second synthetic activity/navigation soak: 3,720 tool events, approximately 288 rapid menu interactions, bounded virtual rows and stable memory after warmup in this measured interval.
- Windows Setup and Portable packaged with 19/19 release gates, clean exact-revision provenance, binary SHA-256 and packaged recovery, stdio/MCP and TypeScript diagnostics smokes.

## Known limitations — preview release

- **17 of 48 animation-rework checklist items remain pending.** This includes optional shared-element interactions, exhaustive live per-page states, real-game CPU/GPU presentation analysis, physical 120/144/165 Hz monitors, and longer endurance tests. Native callback sampling near 60 Hz does **not** guarantee 60 FPS under every workload.
- The release pipeline has not certified the user’s live installed update/rollback, actual signed-in ChatGPT host/tunnel end-to-end, or Delta Force foreground performance.
- **Windows binaries are unsigned (Authenticode: NotSigned).** Windows SmartScreen may display an unknown-publisher warning. Compare artifact SHA-256 values listed in release evidence.
- Neither the installer nor Portable build was automatically installed on the user's device as part of this release. Existing user settings and local Memory should be preserved, but full installed-upgrade and rollback acceptance are still pending.

## Try the preview

Download the Windows **Portable** executable to inspect the new interface without running Setup. Avoid launching it simultaneously with an installed Qnector connected to the same tunnel/profile unless the instance is explicitly isolated. A normal installation/update should be scheduled after checking active tasks and backing up the local profile.
