# Qnector v0.4.59 - Activity Visibility and Motion Refinements (Preview)

**Preview release:** This update includes the latest Activity Feed, Queen orb, and Royal Silk fixes. Other animation-rework acceptance gates remain pending.

## Changes since v0.4.58

- **Always-visible Skill attribution:** Every Live Activity task displays activated Skill names inside its own row without mouse hover. Multiple Skills appear together; direct calls explicitly display **DIRECT TOOL**. The expanded lower line stays within the row even in compact windows.
- **Activity Feed usability:** More vertical space for real tool events, with a smaller decorative orb and sharper static Queen emblem. The Running task uses a restrained slim gold progress sweep and illuminated status badge in place of a large flashing yellow ripple.
- **Smooth orb disconnect:** Preserve orbital angle while entering and leaving the three-second hold action, eliminating the visible animation phase jump and avoiding unnecessary image resampling.
- **Royal Silk continuity:** Keep the ambient animation phase across window resizes without clearing its Canvas when the backing dimensions are unchanged. The shared animation clock does not insert unwanted static frames.
- **Isolated synthetic preview cleanup:** Remove the tiny fixed-position **SIMULATED - NO LIVE MCP DATA** overlay that appeared behind the native header border. The preview is now clearly labeled **QNECTOR Preview - SIMULATED DATA** in the native window title instead. No production UI is labeled simulated.

## Safety and compatibility

- Existing NoPlan architecture, MCP bridge, local Memory and other features are retained.
- The isolated Preview uses synthetic data and a mutation-blocked bridge; its visual QA does **not** demonstrate a successful live ChatGPT/Tunnel session.
- Motion at physical 120/144/165 Hz displays, real-game load, full installed upgrade/rollback and remaining animation-rework checklist gates have **not** been validated by this change.
- **Unsigned Windows binaries:** No Authenticode signing certificate is available; SmartScreen may warn. Check SHA-256 against release evidence before running.
- This release does not automatically install/replace Qnector on the user device.

## Verification

- Focused renderer/preview tests and native Electron layout across 475x865, 435x900, 420x620 and 700x900.
- Release packaging and runtime smoke tests are required before GitHub publication; do not interpret this document alone as evidence that the assets have been published.

Use the **Portable** Windows build for independent UI inspection, or the **Setup** build to install when ready. Do not run multiple live instances against the same production profile or tunnel without isolation.
